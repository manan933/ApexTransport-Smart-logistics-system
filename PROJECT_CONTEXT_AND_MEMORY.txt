1. EXECUTIVE OVERVIEW & PLATFORM IDENTITY
--------------------------------------------------------------------------------
Apex Transport (formerly TruckMate / LogisticMS) is a production-grade, full-stack 
cyber-logistics freight operating system engineered for the Indian commercial road 
transport ecosystem. It connects Transporters (Shippers / Fleet Operators), Drivers 
(Pilots / Owner-Operators), and Enterprise Admins into a real-time, high-precision 
freight booking, live tracking, automated escrow payout, and auditing platform.

AESTHETIC & BRAND IDENTITY:
- Theme: Obsidian Charcoal & Emerald Cyber-Logistics Command Center
- Primary Background: #0B0F17 (Deep Obsidian) & #111827 (Charcoal Card Surface)
- Accent Colors: #10B981 / #059669 (Emerald Freight Glow), #34D399 (Active Transit),
  #F59E0B (Amber Warning/Pending), #EF4444 (Critical SOS/Alert), #6366F1 (Digital HUD)
- Primary UI Typography: Google Sans / Outfit (Modern, high-legibility sans-serif)
- Brand Display Typography: Boldonse (Reserved exclusively for APEX branding)
- Tone: High-tech, military-grade telematics command deck. Strictly avoids generic blues.

2. SYSTEM ARCHITECTURE & TECH STACK
--------------------------------------------------------------------------------
BACKEND ARCHITECTURE (Spring Boot 3.5.11 / Java 17):
- Framework: Spring Boot 3.5.11 with Spring Data JPA & Spring Security Crypto (BCrypt).
- Web Layer: REST API (@RestController) with explicit JSON serialization and 
  Jakarta HttpSession cookie-based stateful authentication.
- Single-Page Application (SPA) Forwarding: Custom SpaForwardingController routes all 
  HTML5 navigation paths (/, /login, /transporter/**, /driver/**, /admin/**, /profile/**) 
  directly to static HTML dashboards.
- Database: Dual-mode support:
  * Local Dev: H2 In-Memory with schema auto-generation and DataSeeder.
  * Production: PostgreSQL with Hibernate dialect and connection pooling.
- Storage Service (StorageService.java): Local disk & Base64 image processor handling 
  Proof of Delivery (POD) signed slips, cargo consignment photos, PDF invoices, 
  and user profile avatars.
- Audit & Security (AuditLogService.java): Synchronous event audit logger capturing 
  every platform action, user role, category, and client IP address.

FRONTEND ARCHITECTURE:
- Pure Vanilla Web Standards: Pure HTML5, Vanilla CSS3 (main.css), and Modular ES6 
  JavaScript (api.js, i18n.js, audio-alerts.js) for ultra-fast, zero-dependency rendering.
- Telematics & Mapping: Leaflet.js with OpenStreetMap tiles and dynamic route polylines.
- Audio Synthesis: Web Audio API Dual-Tone Synthesizer (C5 -> G5 sine-wave pulses) 
  for real-time harmonic chimes on load claiming, transit dispatch, and POD delivery.
- Internationalization (i18n): Client-side bilingual engine supporting English and 
  phonetic Hinglish tailored for Indian transport yard operators.

5. REST API ENDPOINT CATALOG
--------------------------------------------------------------------------------
AUTH CONTROLLER (`/api/auth`):
- `POST /api/auth/login`          : Authenticate with email & password -> Sets session cookie
- `POST /api/auth/register`       : Register new Transporter or Driver account
- `GET  /api/auth/me`             : Returns 200 OK with { authenticated: true/false, user: {...} }
- `POST /api/auth/logout`         : Invalidate session
- `POST /api/auth/profile`        : Update profile details, vehicle info, avatar/banner base64

TRANSPORTER CONTROLLER (`/api/transporter`):
- `GET  /api/transporter/dashboard`             : Summary metrics, active/pending counts, orders
- `GET  /api/transporter/orders`                : Full list of transporter's posted orders
- `POST /api/transporter/orders/create`         : Post new consignment with full specs & files
- `POST /api/transporter/orders/{id}/rate-driver`: Inspect POD, release payment & submit rating
- `GET  /api/transporter/logs`                  : Transporter activity & audit logs

DRIVER CONTROLLER (`/api/driver`):
- `GET  /api/driver/dashboard`                  : Driver dashboard metrics & current job
- `GET  /api/driver/orders/available`           : Available loads matching vehicle/location
- `GET  /api/driver/orders/current`             : Active accepted/in-transit job
- `POST /api/driver/orders/{id}/accept`         : Claim and lock an available consignment
- `POST /api/driver/orders/{id}/start`          : Start transit & activate GPS tracking
- `POST /api/driver/orders/{id}/complete`       : Submit signed POD challan & complete delivery
- `POST /api/driver/orders/{id}/rate-shipper`   : Submit shipper rating & feedback
- `GET  /api/driver/logs`                       : Driver trip and audit logs

ADMIN CONTROLLER (`/api/admin`):
- `GET  /api/admin/dashboard`                   : Global platform telemetry & revenue metrics
- `GET  /api/admin/orders`                      : All platform orders across India
- `GET  /api/admin/users`                       : All registered users and driver fleet
- `GET  /api/admin/logs`                        : Master platform audit trails
- `POST /api/admin/users/{id}/toggle-status`    : Suspend or activate accounts

SHARED / UTILITY CONTROLLER (`/api`):
- `GET  /api/locations/suggest`                 : Auto-suggest major Indian industrial hubs
- `GET  /api/orders/{id}/coordinates`           : Real-time order origin, dest & current GPS
- `GET  /api/notifications/recent`              : Unread & recent in-app notifications
- `POST /api/notifications/mark-read/{id}`      : Mark specific notification as read

7. EVOLUTION & RESOLUTION CHRONOLOGY (KEY LESSONS LEARNED)
--------------------------------------------------------------------------------
1. SESSION PROBE / 401 EXCEPTION HARDENING:
   - Issue: When users refreshed unauthenticated dashboards, `/api/auth/me` returned 401, 
     triggering unhandled promise rejections ("Error refreshing pilot deck" toasts).
   - Fix: Updated `RestAuthController.java` to return HTTP 200 with `{ "authenticated": false }`. 
     Updated `api.js` to handle unauthenticated state smoothly by redirecting to `/login.html`.

2. REMOVAL OF LEGACY THYMELEAF TEMPLATES:
   - Issue: Legacy templates in `src/main/resources/templates/` with old blue styling were 
     intermittently intercepted by Spring Boot's ThymeleafViewResolver on non-.html paths.
   - Fix: Completely removed `templates/` directory, deleted Thymeleaf starters from `pom.xml`, 
     and routed all navigation via `SpaForwardingController.java` to modern static SPAs.

3. ASSET CACHE-BUSTING:
   - Issue: Browser aggressive caching caused users to occasionally see stale CSS or JS.
   - Fix: Added `?v=3.5` query versioning to all CSS and JS script tags across all HTML files.

4. PRICE / ESCROW MAPPING:
   - Issue: `Order` entity `amount` property vs frontend `price` property resulted in undefined spend.
   - Fix: Updated `RestTransporterController.formatOrder()` to expose both `amount` and `price` 
     keys seamlessly.
